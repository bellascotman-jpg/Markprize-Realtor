# Markprize Realtor Group

Professional static website for Markprize Realtor Group, Lagos, Nigeria.

## Source
The property catalogue is connected to the business's live Jiji seller page:
https://jiji.ng/sellerpage-857LwZPszM1SmsnnulRBurOO

The site uses only property details visible on the seller page and clearly notes that prices/availability must be verified.

## Hosting
This repository is configured for GitHub Pages via GitHub Actions. After the workflow completes, the site is available from the repository's GitHub Pages URL.

## Update
Property prices, availability and contact details should be refreshed whenever the Jiji catalogue changes.
